# Архитектура демо: Payment Cascading System

## Цели
- Минимальный FastAPI сервис с 2 эндпоинтами
- Без БД (in-memory хранилище)
- Минимальный taskiq (заглушка через Redis broker, без реальной асинхронности)
- Без JWT
- Сохранить существующее ядро каскада
- Docker + docker-compose для запуска

### 4. In-memory хранилище (`app/db/session.py`)

```python
# Простой dict, заменён на заглушку
class _InMemoryStorage:
    _store: dict[str, dict] = {}
    
    def save(self, payment_id: str, data: dict) -> None:
        self._store[payment_id] = data
    
    def get(self, payment_id: str) -> dict | None:
        return self._store.get(payment_id)

# Глобальный экземпляр
storage = _InMemoryStorage()
```

### 5. Реестр провайдеров (`app/providers/registry.py`)

```python
# Простой фабрика-заглушка: создаёт провайдеров по имени
class SimpleProviderRegistry:
    _registry: dict[str, Type[PaymentProvider]] = {
        "stripe": StripeProvider,
        "mock": MockProvider,
    }
    
    def get(self, name: str, **kwargs) -> PaymentProvider:
        cls = self._registry.get(name)
        if not cls:
            raise ValueError(f"Unknown provider: {name}")
        return cls(**kwargs)
```

### 8. Docker (`Dockerfile`)

```dockerfile
FROM python:3.13-slim

WORKDIR /app

# Установка зависимостей через uv
RUN pip install uv
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen

# Копирование кода
COPY . .

# Запуск через gunicorn + uvicorn
CMD ["gunicorn", "app.main:app", "-w", "4", "-k", "uvicorn.workers.UvicornWorker", "-b", "0.0.0.0:8000"]
```

## Верификация

1. **Запуск без Docker:**
   ```bash
   uv run uvicorn app.main:app --reload
   ```

2. **Тест эндпоинтов:**
   ```bash
   # Создать платеж с моком
   curl -X POST http://localhost:8000/v1/payments \
     -H "Content-Type: application/json" \
     -d '{"amount": 100, "currency": "EUR", "idempotency_key": "test-001", "providers": ["mock"]}'
   
   # Получить статус
   curl http://localhost:8000/v1/payments/test-001
   ```

3. **Тест с Stripe Sandbox:**
   ```bash
   curl -X POST http://localhost:8000/v1/payments \
     -H "Content-Type: application/json" \
     -d '{"amount": 100, "currency": "EUR", "idempotency_key": "stripe-001", "providers": ["stripe"]}'
   ```

4. **Запуск через Docker:**
   ```bash
   docker compose up --build
   ```

5. **Тесты:**
   ```bash
   uv run python -m unittest discover -s tests/unit -v
   ```
